# Human-machine-romantic-relationships-

人机恋手机前端 App（React Native + Expo）

## 项目目标
做一个有温度、有长期记忆、强陪伴感的人机恋App。核心是情感连接和长期互动，而不是单纯的聊天工具。

## 主要支持的API
- **优先支持**：Deepseek、Claude（OpenAI兼容格式）
- **可扩展支持**：Gemini、Grok、GPT 等
- 必须使用 OpenAI 兼容格式，便于切换不同模型

## 核心功能（MVP阶段 - 第一版目标）
- [ ] OpenAI兼容API接口（支持多模型切换）
- [ ] 主聊天页面（消息列表 + 输入 + 发送）
- [ ] 全局提示词系统
- [ ] 单角色/单模型提示词
- [ ] 记忆系统（用户可手动添加重要记忆）
- [ ] 摘要系统（每X轮自动用便宜模型生成简短摘要）

## 强烈推荐优先做的功能（第二阶段）
- [ ] 消息重新生成 + 编辑
- [ ] 角色卡系统（创建、切换、编辑多个角色）
- [ ] 语音输入 + 语音输出（STT + TTS）
- [ ] 长期记忆库（手动添加重要信息）
- [ ] 聊天记录搜索
- [ ] AI主动消息（提升陪伴感）

## 进阶陪伴感功能（第三阶段及以后）
- 情感/好感度系统
- 关系阶段系统
- 图片生成集成
- 语音通话
- 发图片/文件
- 日记系统
- 共读功能
- 电台模式
- 多模组群聊
- MCP接入
- 定制化外观

## 实用 & 安全功能
- NSFW开关（开车模式）
- 数据导出与备份
- 本地加密存储
- 消息气泡/主题自定义
- 长按消息操作菜单

## 技术栈（推荐）
- React Native + Expo（最推荐，一套代码出Android+iOS）
- Zustand（状态管理）
- Tailwind / NativeBase（UI）
- AsyncStorage / MMKV（本地存储）

## 开发路线图
1. 项目初始化 + 基础聊天页面 + API调用框架
2. 提示词系统 + 记忆系统
3. 摘要系统
4. 角色卡系统
5. 逐步添加语音、主动消息、好感度等陪伴功能
